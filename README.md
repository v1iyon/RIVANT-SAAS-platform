# RIVANT

Бізнес-аналітика для власників малого й середнього e-commerce/сервісного
бізнесу. Продукт підключається до продажів, рекламних кабінетів і
бухгалтерії клієнта, автоматично рахує виручку, витрати, маржинальність і
CAC, будує прогнози та алерти.

Цей README — короткий технічний orientation для розробників, які вперше
відкривають репозиторій, а не маркетинговий текст.

## Стек

- **Frontend / фреймворк**: Next.js (App Router) + React, TypeScript
- **Стилі / UI**: Tailwind CSS, Radix UI
- **Backend / БД**: Supabase (PostgreSQL, Auth, Edge Functions), Row Level
  Security увімкнено на всіх таблицях
- **Хостинг**: Vercel (serverless + вбудовані cron-задачі)
- **Платежі**: Ko-fi та крипто (USDC/Polygon) — прийом оплати підписки
  клієнтами RIVANT; Stripe/Shopify/WooCommerce/PayPal/Mollie/QuickBooks —
  ІНШЕ: це джерела даних, які клієнт підключає своїм ключем, щоб платформа
  порахувала ЙОГО виручку (read-only, гроші по цих ключах до RIVANT не
  надходять)
- **AI-інсайти**: Anthropic API (прогноз, алерти, What-If звіт)
- **Telegram-бот**: grammy

## Структура репозиторію

```
app/
  api/          — серверні маршрути (метрики, підписки, інтеграції, вебхуки, cron)
  admin/        — адмін-панель
  dashboard/    — особистий кабінет клієнта (page.tsx, основний екран)
components/     — UI-компоненти (дашборд, лендинг, shadcn/ui-обгортки)
lib/            — бізнес-логіка: маржа, валюти, шифрування, таймзони, права доступу
scripts/        — фонові скрипти синку з зовнішніми сервісами (крон)
supabase/
  migrations/   — еволюція схеми БД
  functions/    — Edge Functions (вебхуки оплати, email, замовлення)
```

## Локальний запуск

```bash
npm install
cp .env.local.example .env.local   # заповнити реальними ключами (Supabase, Anthropic, тощо)
npm run dev
```

Список усіх потрібних змінних середовища — у `.env.local.example`
(секретні ключі там НЕ закомічені, лише назви змінних).

## Синхронізація з зовнішніми сервісами

`scripts/*-sync.mjs` — окремий скрипт на кожен інтегрований сервіс
(Stripe, Shopify, WooCommerce, PayPal, Mollie, QuickBooks, Meta Ads,
Google Ads). Запускаються погодинно через `scripts/run-sync.mjs`,
розклад — `.github/workflows/sync-stripe.yml` (детальніше про джерело
розкладу — коментар на початку самого файлу).
